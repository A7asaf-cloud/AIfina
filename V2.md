# AIfina V2

## Run locally

Install dependencies with `npm install`. Run `npm run dev` and open
http://127.0.0.1:3000. Development binds to loopback; production can use `HOST`.
The demonstration sign-in opens browser-local sample data, separate from personal records.

## Cash-flow model

- `bankBalance` is a reported snapshot, dated with `balanceAsOf`.
- Explicit posted transactions with `balanceIncluded: false` adjust that snapshot.
  Legacy records are treated as already included for backward compatibility.
- `planned` and `pending` records remain forecasts until confirmed. Merely reaching
  a salary or standing-order date does not post a transaction or an investment deposit.
- Expected salary, rent, active standing orders and entered credit settlements are
  included once. Overdue plans remain visible. Monthly recurrence days clamp to
  the last calendar day. Calendar keys do not pass through UTC conversion.
- Variable-expense reserve is the remaining configured monthly variable budget.
  The safety buffer reduces spending allowance, not projected bank balance.
- Spendable cash is conservative: current balance less commitments, variable
  reserve and buffer. It does not spend expected income before receipt.
- The forecast includes expected income and daily variable reserves. It is an
  estimate from entered records, not a live-bank verification.
- Card purchases and linked settlements are distinct. Unknown card settlement
  dates are flagged; the entered aggregate should be reconciled by the user.

## Checks

`npm test` runs the categorization and cash-flow regression suites.
`npm exec tsc -- --project tsconfig.app.json --noEmit` checks the app separately
from the optional finance-scraper service. `npm run build` builds client and server.
The existing root lint configuration also includes the independently installed
finance-scraper service and requires its dependencies.

## Scope

The existing authentication, onboarding, bank import, budgets and investments are
retained. V2 adds a responsive cash-flow dashboard, explicit transaction planning,
editing, confirmation/cancellation, and editable cash-flow assumptions. Live bank
connections and remote synchronization have not been reimplemented or certified
by this change.
